## 2. Full Description (Mô tả chi tiết - Copy vào Partner Center)

### English:
```text
🚀 INSTANT ACCESS: Press Ctrl + Shift + V anywhere to toggle your clipboard history!
(You can also click the clipboard icon in your system tray or customize your hotkey in Settings).

Advanced Clipboard Manager is a lightweight, lightning-fast, and secure clipboard utility designed for Windows 10 & 11. It quietly sits in your system tray, captures everything you copy (text, code, images, files, links), and lets you paste anything back in a split second.

✨ KEY FEATURES:
• ⌨️ Global Quick Paste (Ctrl+Shift+V): Access your entire clipboard history from any application.
• 🔍 Instant Full-Text & Filter Search: Search by keywords or filter by type (Code, Images, Links, Snippets, Pinned).
• 🔒 Smart Privacy & Secret Protection: Automatically masks passwords, API tokens, and private keys. Set auto-expiration rules or DPAPI hardware-level encryption.
• 🖼️ Offline OCR for Images: Search and copy text trapped inside screenshots and images using offline Windows OCR.
• 📚 Paste Stack (Sequential Paste): Select multiple items and paste them one-by-one with Ctrl+V in order.
• 🏷️ Quick Snippets & Dynamic Templates: Insert frequently used phrases with variables like {date}, {time}, and {clip}.
• 🎨 Modern Windows 11 Fluent Design: Beautiful acrylic blur, dark/light theme, and customizable compact widget mode.
• 🚀 100% Offline & Private: No telemetry, no cloud syncing, zero external network requests. Your data never leaves your computer.
```

### Tiếng Việt:
```text
🚀 TRUY CẬP NHANH: Bấm Ctrl + Shift + V ở bất kỳ đâu để mở lịch sử sao chép!
(Bạn cũng có thể nhấp vào biểu tượng khay hệ thống hoặc tùy chỉnh phím tắt theo ý muốn trong Cài đặt).

Advanced Clipboard Manager là ứng dụng quản lý lịch sử sao chép thông minh, siêu nhẹ và an toàn tuyệt đối dành cho Windows 10 & 11. Ứng dụng chạy nền tĩnh lặng dưới khay hệ thống, tự động lưu lại những gì bạn sao chép (văn bản, mã nguồn, hình ảnh, tập tin, liên kết) và giúp bạn dán lại tức thì.

✨ CÁC TÍNH NĂNG NỔI BẬT:
• ⌨️ Phím tắt toàn cục (Ctrl+Shift+V): Gọi cửa sổ lịch sử clipboard ở bất kỳ ứng dụng nào bạn đang dùng.
• 🔍 Tìm kiếm toàn văn siêu tốc: Tìm theo từ khóa hoặc lọc theo danh mục (Code, Ảnh, Link, Mẫu tin, Ghim).
• 🔒 Bảo vệ quyền riêng tư & Mật khẩu: Tự động ẩn API key, token và mật khẩu. Mã hóa cơ sở dữ liệu với Windows DPAPI an toàn.
• 🖼️ Trích xuất chữ từ ảnh (OCR offline): Tìm kiếm và copy lại chữ trong ảnh chụp màn hình hoàn toàn offline.
• 📚 Paste Stack (Dán hàng đợi liên tục): Chọn nhiều mục và dán lần lượt từng mục bằng phím Ctrl+V.
• 🏷️ Mẫu văn bản gõ nhanh (Snippets): Tạo sẵn các mẫu văn bản hay dùng kèm biến động {date}, {time}, {clip}.
• 🎨 Giao diện Windows 11 Fluent hiện đại: Hiệu ứng kính mờ Acrylic trong suốt, bo tròn tinh tế và chế độ widget nhỏ gọn.
• 🚀 Bảo mật 100% Offline: Hoàn toàn không thu thập dữ liệu, không kết nối máy chủ ngoại vi, dữ liệu chỉ lưu trên máy bạn.
```

## 3. Product Features (Bullet points trên Microsoft Store)

1. Press Ctrl+Shift+V anywhere to quickly paste recent clippings
2. Intelligent content classifier (Code, URLs, Passwords, Secrets, Files, Images)
3. Offline OCR text recognition inside images and screenshots
4. Smart sensitive data masking with automatic expiration
5. Multi-item merge paste and sequential Paste Stack
6. Reusable text snippets with dynamic expansion tags
7. System tray integration with left-click instant access
8. Zero cloud syncing, 100% local DPAPI encrypted storage
