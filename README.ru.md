# Advanced Clipboard Manager

[English](README.md) • [Tiếng Việt](README.vi.md) • [简体中文](README.zh.md) • [日本語](README.ja.md) • [한국어](README.ko.md) • [Español](README.es.md) • [Français](README.fr.md) • [Deutsch](README.de.md) • [Русский](README.ru.md) • [Português](README.pt.md)

Менеджер буфера обмена для Windows 10/11 и macOS, разработанный с упором на локальное хранение данных (**local-first**) и управление с клавиатуры (**keyboard-first**). Автоматически сохраняет историю, классифицирует скопированные фрагменты по типам и позволяет мгновенно вставлять любые данные по нажатию **Ctrl+Shift+V** (или через меню в строке меню на macOS).

## Возможности

| Возможность | Описание |
|---|---|
| История буфера обмена | Сохраняет каждый скопированный фрагмент от новых к старым. Поддерживает форматированный текст, изображения и файлы. Одинаковые копии объединяются со счетчиком повторений. |
| Быстрая вставка (Quick Paste) | **Ctrl+Shift+V** открывает поисковую панель. Стрелки для навигации, **Enter** вставляет прямо в активное приложение. |
| Автоматическая классификация | Встроенные локальные правила определяют: SQL, JSON, XML, YAML, shell-скрипты, исходный код, логи, URL (GitHub...), email, номера телефонов, числа, IP-адреса и Markdown. |
| Динамический предпросмотр | Подсветка синтаксиса для кода/SQL/JSON; просмотр изображений с разрешением (`PNG · 1103 × 593`) и офлайн OCR-распознаванием текста; карточки ссылок URL; безопасное маскирование конфиденциальных данных с открытием по **Ctrl+R**. |
| Мгновенный поиск | Полнотекстовый поиск SQLite FTS5 с префиксным совпадением и фильтрами: `type:sql`, `type:snippet`, `type:image`, `pinned:true`, `sensitive:true` и др. |
| Сохранение форматирования | Сохраняет стили HTML/RTF при вставке по **Enter**. Используйте **Ctrl+Shift+Enter** для вставки обычного текста (или распознанного OCR текста из изображения). |
| Быстрая вставка по номерам | Первые 9 строк пронумерованы: **Ctrl+1…9** вставляет элемент напрямую (`Shift` для вставки без форматирования). |
| Преобразование текста | **Ctrl+K** (или правый клик) для форматирования перед вставкой: ВЕРХНИЙ/нижний регистр, удаление пробелов, объединение строк, форматирование JSON/SQL, кодирование/декодирование Base64 и URL. |
| Последовательная вставка (Paste stack) | Отметьте нужные элементы по порядку через **Ctrl+Space** и запустите стек по **Ctrl+S**. Каждое последующее нажатие **Ctrl+V** будет вставлять следующий элемент по цепочке. |
| Сниппеты и шаблоны (Snippets) | Сохраняйте часто используемый текст: **Ctrl+N** для создания, **Ctrl+E** для редактирования. Переменные: `{date}`, `{time}`, `{datetime}`, `{date:yyyy-MM-dd}`, `{clipboard}`, `{uuid}`. |
| Офлайн OCR распознавание | Встроенный офлайн OCR движок Windows распознает текст на скриншотах, позволяя искать изображения по содержимому и вставлять их как текст. |
| Боковая панель (Sidebar) | **Ctrl+D** закрепляет панель у границы экрана (режим AppBar). |
| Локальное шифрование | Опциональное шифрование через учетную запись Windows (DPAPI) без паролей. Данные шифруются на диске, поисковый индекс находится только в оперативной памяти. |
| Закрепление (Pin) | **Ctrl+P** закрепляет важные элементы. Они не удаляются со временем и всегда находятся вверху. |
| Автоматическое удаление | Настраиваемое время хранения по типам: секреты 5 мин, пароли 1 мин, текст 1 день, код/URL 7 дней, изображения 1 час. |
| Конфиденциальность | Все данные хранятся исключительно локально в `%LOCALAPPDATA%\ClipboardManager` (Windows) или `~/Library/Application Support/ClipboardManager` (macOS). Никаких запросов в сеть. |

### Сочетания клавиш

| Сочетание | Действие |
|---|---|
| `↑` `↓` `PgUp` `PgDn` | Навигация по списку |
| `Enter` | Вставить (объединяет несколько выбранных) |
| `Ctrl+Shift+Enter` | Вставить как обычный текст |
| `Ctrl+1` … `Ctrl+9` | Вставить элемент 1…9 (`Shift` для обычного текста) |
| `Ctrl+K` / Правый клик | Преобразовать текст и вставить |
| `Ctrl+C` | Скопировать в буфер обмена без вставки |
| `Ctrl+P` | Закрепить / Открепить |
| `Ctrl+Space` | Множественный выбор (сохраняет порядок) |
| `Ctrl+S` | Запустить стек последовательной вставки |
| `Ctrl+N` / `Ctrl+E` | Создать сниппет / Изменить сниппет |
| `Ctrl+R` | Показать скрытые конфиденциальные данные |
| `Ctrl+T` | Закрепить окно поверх остальных |
| `Ctrl+D` | Закрепить как боковую панель: Справа → Слева → Выкл |
| `Ctrl+L` | Сменить пропорцию разделения: 25/75, 30/70, 40/60, 50/50 |
| `Ctrl+M` | Переключить режим компактного виджета / полного окна |
| `Ctrl+Shift+T` | Включить / выключить прозрачность акрила |
| `Ctrl+,` | Открыть настройки |
| `F1` | Показать справку по горячим клавишам |
| `Del` | Удалить элемент |
| `Esc` | Закрыть панель |

## Сборка и запуск (Windows)

Требования: Windows 10/11 x64 и [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (`winget install Microsoft.DotNet.SDK.8`).

```powershell
.\build.ps1            # Сборка + тесты
.\build.ps1 -Run       # Сборка и запуск (Ctrl+Shift+V)
.\build.ps1 -Publish   # Создать автономный exe в .\publish\
.\build.ps1 -Installer # Создать Setup.exe в .\dist\
.\build.ps1 -Msix      # Создать пакет Microsoft Store (.msix)
```
